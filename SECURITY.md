# Security and Responsible Use

## Supported use

OncoSource Studio is an educational portfolio demonstration using synthetic data. It may be used to discuss clinical data design, testing, interoperability and software architecture.

## Prohibited use

Do not:

- enter real patient or participant data;
- use the application to make treatment decisions;
- deploy it as a clinical trial source system;
- claim regulatory compliance or validation;
- connect it to a production EHR, EDC or safety system; or
- store credentials or protected health information in the repository.

## Reporting a security concern

Open a private security advisory in the GitHub repository rather than posting sensitive details in a public issue.
